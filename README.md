# MapSystem · 交互式地图导航与虚拟街景系统

> UID（User Interface Design）课程期末 Project 2
> 仓库地址：https://github.com/xinwang540/MapSystem

基于 MATLAB（uifigure 程序化 GUI）实现的交互式地图应用：以一张校园 / 园区平面图 `MapForUI.jpg` 为底图，支持手绘式道路网络提取、栅格最短路径规划、车辆（IV）投放与管理、距离 / 轨迹测量，以及由顶视地图实时渲染的第一视角虚拟街景。

---

## 功能特性

### 道路网络
- **交互式道路提取**：在「提取道路」模式下依次点击两个道路点，系统沿两点连线做合法性校验并自动生长出一段可通行道路掩码（亮蓝色叠加显示）；双击非道路区域可撤销上一段提取。
- **道路合法性判定**：基于邻域像素亮度与灰度方差投票，判断点击位置是否落在真实道路区域，非法落点直接拦截并提示。
- **查看道路**：一键切换为仅显示已提取路网的白底视图，方便检查提取结果。

### 路径规划
- **BFS 最短路径**：在已提取路网内依次点击起点、终点，系统在栅格掩码上以 8 邻域 BFS 搜索最短通路，红色渲染路径，并按 1 像素 = 1.7 米换算输出实际物理距离。
- **状态反馈**：起终点重合、路网内无连通路径、未提取道路即导航等异常情况均弹窗提示并更新状态栏。

### 测量工具
- **两点测距**：依次点击两点，输出两点坐标与直线距离（米）。
- **轨迹长度**：连续点击记录漫游点，实时累计折线总长度（米）与点数。

### 车辆（IV）管理
- **投放车辆**：必须落在已提取路网内；投放时基于邻域路网主成分分析（PCA 特征向量）自动估计车辆朝向。
- **删除车辆**：点击附近最近的车辆（50 米阈值内）进行删除。
- **车辆选择与姿态调整**：下拉框切换当前选中车辆，数值框输入朝向角度并旋转；支持 0.2–5 倍车辆缩放。
- **车辆报告**：一键在日志区输出全部车辆的坐标（米）与朝向角度。

### 局部视图
- 以选中车辆为中心，按设定半径（10–300 米）圆形裁剪放大局部地图，圈外区域置灰；可调整半径、退出回全局视图，局部视图内的点击坐标会自动映射回全图坐标系。

### 虚拟街景
- 在道路上点击后，基于**针孔相机模型**由顶视地图实时反投影生成第一视角街景图：相机高 2 米、焦距 380，地面采样点双线性插值取色，地平线以上渲染天空色；支持「左转 15° / 右转 15°」连续调整视角偏航角。
- 朝向取自该位置邻域路网的 PCA 主方向。

### 全局视图操作
- **地图旋转**：滑块 / 数值框联动（-180° ~ 180°），底图与路网掩码同步旋转，鼠标点击坐标通过逆旋转变换映射回原始图像。
- 全窗口自适应居中布局：左侧地图画布 + 右侧控制台。

## 环境要求与运行方式

### 方式一：MATLAB 源码运行
- MATLAB R2020b 或更高版本（使用 `uifigure` / `uiaxes` / `uidropdown` 等 App Designer 风格组件）。
- 将本目录加入 MATLAB 当前路径，确认 `MapForUI.jpg` 与所有 `.m` 文件在同一目录，命令行运行：

```matlab
mapUI
```

### 方式二：免安装 exe（Windows）
- 双击 `mapUI.exe` 即可启动；首次运行需安装对应版本的 **MATLAB Runtime（MCR）**，所需产品列表见 `requiredMCRProducts.txt`。

## 快速开始

1. 启动后点击 **「提取道路」**，在地图道路上连续点击连接多段路网（亮蓝叠加层）；点错可双击撤销。
2. 点击 **「规划路径」**，在蓝色路网内依次点击起点（绿圈）与终点（红圈），自动搜索并绘制红色最短路径，状态栏显示全长（米）。
3. 点击 **「加载车辆」**，在路网内点击投放车辆（自动估计朝向）；可在下拉框选中车辆后调整朝向、缩放。
4. 点击 **「生成街景」**，在有效道路上点击，弹出该位置的第一视角虚拟街景窗，用左右按钮旋转视角。
5. 需要测距用「两点测距」，需要量漫游长度用「轨迹长度」，需要看某车周边环境用「局部地图」。

## 关键设计说明

- **坐标系与比例尺**：屏幕像素坐标 (列 c, 行 r) 与物理坐标的换算关系为 `X = c × 1.7`、`Y = (803 − r) × 1.7`，即 1 像素对应 1.7 米，0° 为正右（+X），90° 为正上（+Y）。
- **状态管理**：全部运行时状态集中在全局结构体 `AppState`（地图、路网掩码、起终点、路径、车辆列表、视图参数、控件句柄），渲染与交互函数均读写该状态。
- **路网掩码**：`skelMask` 为逻辑二值图；道路提取时沿连线采样合法像素并以 BFS 在 25 像素半径内生长掩码，历史快照 `MaskHistory` 支持双击撤销。
- **寻路**：8 邻域 BFS（对角步长经真实物理距离累加），路网先做 3×3 闭运算弥合小缝隙；无路网时降级为全图保底搜索并告警。
- **车辆朝向估计**：对点击点 30 像素邻域内的路网像素做 PCA，取最大特征值对应特征向量作为道路切线方向。
- **街景渲染**：每个输出像素按针孔相机模型反求地面坐标，再双线性插值采样底图像素；相机俯仰固定，仅支持偏航角（左右 15° 步进）调整。
